# دليل الحسابات — بيانات تأسيسية

> نظرة عامة والقواعد الملزمة في [`data/README.md`](../README.md). هذا الملف مرجع الأعمدة والترقيم.
> **مسودة تنفيذية — لا يُعتمد أي حساب قبل توقيع المحاسب القانوني.**

## الملفات

| الملف | المحتوى |
|---|---|
| `accounts.csv` | صف لكل حساب — 180 صفاً (109 قابل للترحيل · 71 تجميعي) |
| `dimensions.csv` | الأبعاد المتاحة على سطر القيد |
| `subledger-types.csv` | أنواع الدفاتر المساعدة وتقرير المطابقة الواجب لكل منها |
| `ddl/001-schema.sql` | المخطط مع قيود التحقق والمُشغّلات |
| `ddl/002-load.sql` | التحميل من CSV — يُشغَّل من داخل هذا المجلد |
| `ddl/003-checks.sql` | استعلامات تشخيصية تُقرأ بالعين |

الترميز **UTF-8** والفاصل فاصلة والسطر الأول ترويسة. لا تحتوي الحقول فواصل إنجليزية —
النص العربي يستخدم الفاصلة العربية `،` — فيمكن قراءة الملف بأي أداة دون قواعد اقتباس معقدة.

## مبدأ الترقيم

```
1        التصنيف الرئيسي   (مستوى 1 — تجميعي)
11       المجموعة          (مستوى 2 — تجميعي)
110      الحساب الفرعي     (مستوى 3 — تجميعي)
1101     الحساب التفصيلي   (مستوى 4 — قابل للترحيل)
```

**الشجرة مشتقة من الرمز:** المستوى = طول الرمز، والأب = بادئة الرمز. قيد `account_parent_matches_code`
في قاعدة البيانات يمنع أي انحراف بين الرمز والشجرة، وقاعدة `V09` في أداة التحقق تمنعه في البيانات.

## الأعمدة

| العمود | القيم | ملاحظة |
|---|---|---|
| `code` | `^[1-9][0-9]{0,3}$` | يحدد المستوى والأب |
| `name_ar` · `name_en` | نص غير فارغ | **إلزاميان معاً — قيد `not null check` في قاعدة البيانات وقاعدة `V06` في الأداة** |
| `parent_code` | رمز حساب | فارغ للمستوى 1 فقط |
| `level` | 1–4 | = طول الرمز |
| `account_type` | `asset` `liability` `equity` `revenue` `expense` | يجب أن يطابق تصنيف الأب |
| `natural_side` | `debit` `credit` | الطبيعة الافتراضية |
| `is_postable` | `true` `false` | `true` للمستوى 4 حصراً |
| `is_contra` | `true` `false` | الطبيعة معاكسة لتصنيف الحساب |
| `statement_section` | 10 قيم | فارغ للتجميعي، إلزامي للتفصيلي |
| `subledger_type` | رمز من `subledger-types.csv` أو `none` | إلزامي على السطر إن لم يكن `none` |
| `required_dimensions` | مفصولة بـ `\|` | لا ترحيل بدونها |
| `currency_mode` | `any` `company_only` `fixed` | `fixed` يستوجب `currency_code` |
| `currency_code` | `SAR` … | مع `fixed` أو `company_only` |
| `is_protected` | `true` `false` | كل حساب يشير إليه دور محمي إلزاماً (`V15`) |
| `status` | `drafted` `renamed` `proposed` | `proposed` = **يحتاج مراجعة محاسب** |
| `source_ref` | مرجع الوثيقة | من أين جاء الحساب |
| `caveat_ar` · `caveat_en` | نص | `⚠️` = تحفّظ نظامي أو ضريبي لم يُرفع |

## الحسابات المقترحة في هذا التسليم (`status = proposed`)

هذه **لا تسندها أي وثيقة تحليل** وأُضيفت لأن حدثاً في المصفوفة يحتاجها أو لأن الدليل الأساسي
يحمل نصف معالجة. **كلها في طابور المراجعة المحاسبية:**

| الرمز | الحساب | لماذا أُضيف |
|---|---|---|
| `1203` | حساب أمانات الملاك والتأمينات | ق-ع-9 مفتوح: حساب أستاذ مستقل أم حساب بنكي تحت `1201`؟ |
| `1204` | نقدية بالطريق | التحويلات التي لا تُقيَّد في اليوم نفسه — لا وثيقة تغطيها |
| `1309` | مخصص ديون العملاء | الدليل يحمل مصروف المخصص `5603` بلا حساب مقابل للعملاء |
| `1405` | مخزون قطع الغيار | وحدة المخزون بلا وثيقة تحليل |
| `1406` | مخصص تقادم المخزون | وحدة المخزون بلا وثيقة تحليل — والسياسة نفسها تحتاج قراراً |
| `1507` | مجمع إطفاء الأصول غير الملموسة | الدليل يحمل `1504` بلا مجمع إطفاء |
| `3152` | احتياطيات أخرى | اكتمال هيكل حقوق الملكية |
| `39` `390` `3901` | تسوية الأرصدة الافتتاحية | حدث الأرصدة الافتتاحية يحتاج حساباً معلّقاً — يجب أن يتصفّر قبل إقفال أول فترة |
| `5302` | مصروف مخصص تقادم المخزون | يقابل `1406` |
| `5604` | مصروف إطفاء الأصول غير الملموسة | يقابل `1507` |
| `5902` | خصم تعجيل سداد ممنوح | المصفوفة §1.3 تذكر «سطر مصروف مقابل» بلا تسمية حساب |

## قرارات اتُّخذت في هذا التسليم وتحتاج تثبيتاً

1. **`5101` تكلفة البضاعة المباعة تفرض بُعد الفرع.** الدليل الأساسي يفرض الفرع على `4101` ولا يذكره
   لـ `5101` — وبدونه تنكسر ربحية الفرع. أُضيف هنا وموسوم في `caveat`.
2. **العقار بُعد مستقل لا مركز تكلفة.** الوثيقة العقارية تقول `requires_cost_center` وتعني «لا ترحيل
   بلا عقار». فُصل بُعد `property` صراحةً ليقابل «الفرع / مركز التكلفة / المشروع / العقار».
3. **`1202` لا يفرض بُعد الفرع.** فُرض ثم أُسقط لعدم وجود سند له في الوثائق.
4. **`2204` و`2251` تحت المجموعة `22` بحكم رمزيهما** وتُعرضان غير متداولتين بـ `statement_section` —
   حلاً للتعارض بين رمزيهما وعنوان «25» في الوثيقة الأصلية.
