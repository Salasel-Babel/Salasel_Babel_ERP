# matrix-validator — أداة التحقق من البيانات المحاسبية التأسيسية

أداة `net10.0` بلا أي حزمة خارجية، تُحمّل [`data/chart-of-accounts`](../../data/chart-of-accounts)
و[`data/posting-matrix`](../../data/posting-matrix) وترفض الدمج إن كانت البيانات فاسدة.

السبب في وجودها: **دليل الحسابات ومصفوفة الترحيل بيانات، والبيانات التي لا يفحصها شيء تفسد.**
وكل قاعدة أدناه تقابل طريقة يمكن أن تفسد بها هذه البيانات **ولا تظهر إلا كرقم خاطئ في قوائم
مالية لعميل**.

## التشغيل

```bash
dotnet run --project tools/matrix-validator -- --data data     # التحقق
dotnet run --project tools/matrix-validator -- --data data --json
dotnet run --project tools/matrix-validator -- --rules         # قائمة القواعد
dotnet test tools/matrix-validator/tests                       # الاختبارات
```

يخرج بـ `0` عند نجاح كل الفحوص، وبـ `1` عند أي خطأ. التحذيرات لا تُفشل البناء.
إن لم يُمرَّر `--data` بحثت الأداة عن `data/` بالصعود من مجلد العمل.

## كيف يعمل إثبات التوازن (`V03`)

كل تعبير مبلغ يُحلَّل إلى **تركيبة خطية** `Σ (معامل عشري × متغير) + ثابت` — بـ `decimal` لا `double`
([CONTRIBUTING §3.2](../../CONTRIBUTING.md)). ثم لكل سيناريو معلن:

1. تُصفَّر متغيرات `zero_amounts` في كل مكان تظهر فيه، بما في ذلك داخل الهويات
2. تُعوَّض `identities` (هويات الحدث ثم هويات السيناريو) حتى الاستقرار، مع كشف الدوائر
3. تُحسب `Σ(المدين) − Σ(الدائن)`
4. **يجب أن تؤول إلى الصفر المطلق** — كل معامل صفراً والثابت صفراً

الفرق بين هذا وبين «الاختبار برقم»: اختبار برقم يُثبت أن **مثالاً واحداً** يتوازن؛ وهذا يُثبت
أن القاعدة **لا يمكن أن تنتج قيداً غير متوازن مهما كانت المبالغ**.

السطر الوحيد المستثنى: سطر `mirror` المنفرد في حدث عكس القيد — توازنه **موروث** من القيد المصدر
المتوازن، لا مُدّعى.

## الاختبارات

40 اختباراً في [`tests/`](tests):

- **`RealSeedTests`** — البيانات التأسيسية **الحقيقية** التي تُشحن تُحمَّل وتجتاز كل القواعد،
  وليست صغيرة صغراً مريباً، وكل دور يُحلّ إلى حساب قابل للترحيل، وقاعدة الحجب `GR-RE-001`
  موجودة وتشير إلى دور حقيقي، **ولا سطر في أي حدث «مُدار لصالح الغير» يمسّ دور إيراد الإيجار**.
- **`NegativeFixtureTests`** — كل اختبار ينسخ البيانات الحقيقية ثم **يفسد شيئاً واحداً عمداً**
  ويؤكد أن القاعدة المقابلة تُطلق. أداة تحقق لم يكسرها أحد عمداً هي أداة لا يعرف أحد أنها تعمل.
- **`ExpressionTests`** — جبر التعابير: التوازن يؤول إلى صفر، وعدمه لا يؤول، والتعويض يُلغي
  المتغير المعرَّف، وضرب متغيرين مرفوض.
