# واجهة «سلاسل بابل» · Salasel Babel — Front End

واجهة عربية أصالةً، **معزولة تماماً عن الخلفية**: كل ما تعرفه عن الخادم مُولَّد من
`contracts/openapi/v1.json`. لا تُقرأ شيفرة خلفية واحدة لبناء شاشة، ولا يُكتب بيدٍ نوعٌ
يصفه العقد.

* القرار الحاكم: [`ADR-0022`](../docs/decisions/ADR-0022-generated-client-is-the-only-boundary.md)
* لغة السجلّ والترجمة: [`ADR-0021`](../docs/decisions/ADR-0021-arabic-is-the-record-translation-is-presentation.md)
* العقد المنشور: [`ADR-0018`](../docs/decisions/ADR-0018-http-surface-as-a-published-contract.md)
* نظام التصميم المصدر (**للقراءة فقط**): [`design/README.md`](../design/README.md)

## ٠ · الأوامر — كلّها، ومرّة واحدة

```bash
cd web
npm ci                    # أو npm install في أول مرّة

npm run gen               # يولّد العميل من العقد
npm run gen:check         # ✅ البوّابة الحاكمة: إعادة التوليد لا تُنتج أي اختلاف
npm run audit:i18n        # فحص التدويل والاتجاه والمحارف غير المرئية
npm run build             # tsc -b ثم vite build
npm run lint              # ESLint — ومنه قواعد الحدّ المالي
npm test                  # vitest — المال و Display والتدويل
npm run e2e               # يبني ثم Playwright: المصفوفة والسلوك والقياس
npm run verify            # كل ما سبق بالترتيب — بوّابة واحدة
npm run e2e:matrix        # المصفوفة وحدها (٣٢ تركيبة)
npm run perf              # القياس وحده (٥٠٠ صفّاً)
npm run dev               # خادم تطوير، ووسيط إلى الخلفية
npm run mock              # خادم وهمي مطابق للعقد على 5099
```

**البيئة هنا:** المتصفّح مثبَّت مسبقاً في `/opt/pw-browsers/chromium` ولا يُنزَّل
(`playwright install` يفشل). يلتقطه `playwright.config.ts` تلقائياً إن وُجد، ويترك الاختيار
لـPlaywright في التكامل المستمر.

## ١ · ما الذي يجعل العزل حقيقياً

```
contracts/openapi/v1.json        ← المصدر الوحيد. تكتبه الخلفية، ولا تحرّره يد.
        │
        │  node scripts/generate-client.mjs
        ▼
src/api/generated/               ← مُولَّد ومُودَع. لا يُحرَّر بيد.
    contract.ts                     هوية العقد وبصمته sha256
    types.ts                        نوع لكل مخطّط (٢٢)
    client.ts                       دالّة لكل عملية (٦)
    formats.ts                      الأنماط النصّية المنشورة حرفياً
    brands.ts                       الصيغ المحتجزة ومدقّقاتها
    runtime-schema.ts               أين يقع المال في كل مخطّط
```

`npm run gen:check` يُعيد التوليد في الذاكرة ويقارن **البايتات**. اختلاف محرف واحد يوقف
البناء ويسمّي الملفّ والسطر. وهذا مقيس بالمسّ لا بالادّعاء:

```
$ npm run gen:check          # بعد تغيير  accountCode: string  ←  number
✗ الملفات المُولَّدة تخالف العقد. أعِد التوليد: npm run gen
   انحراف · drift in types.ts عند السطر 283
      على القرص · on disk:  "  accountCode: number;"
      من العقد  · from contract: "  accountCode: string;"
exit=1
```

## ٢ · المال — ولماذا كائن لا نصّ

**الرقم يُتلف المال قبل أن يغادر المتصفّح.** مقيس هنا على Node 22.22.2 و Chromium:

| ما يُكتب | ما يخرج |
|---|---|
| `String(Number("1000000000000.4013"))` | `1000000000000.4012` |
| `Number("1000000000000.4013").toFixed(20)` | `1000000000000.40124511718750000000` |
| `JSON.parse('{"d":1000000000000.4013}').d` | `1000000000000.4012` |
| `String(Number("9007199254740993"))` | `9007199254740992` |

ولذلك في هذه الواجهة:

```ts
row.debit            // Money — كائن، لا نصّ ولا رقم
row.debit.text       // "1000000000000.4013"  ← نصّ السلك بايتاً ببايت
row.debit * 2        // TypeError
`${row.debit}`       // TypeError
JSON.stringify(row)  // TypeError
Number(row.debit)    // TypeError
```

والعرض يمرّ بـ`Display` (المنقول من `design/i18n/i18n.js`) الذي ترمي فيه `toString`
و`valueOf` و`toJSON` و`Symbol.toPrimitive` و`localeCompare`. المصرف الوحيد `d.into(el)`،
ومكوّن `<Amount>` هو من يستدعيه. **النوع في TypeScript يُمحى وقت التشغيل؛ الرمي هو
الحارس** (ADR-0021).

⚠️ **العرض تقريب مُعلَن:** المبالغ تُعرض بمنزلتين (مقياس الريال) والقيمة قد تحمل أربعاً،
فنصّ السلك الأصلي يبقى في السمة `title` على كل خانة — لا قيمة بديلة، بل الأصل على بعد
حركة واحدة.

## ٣ · التدويل — منقول لا مُعاد كتابته

المصدر `design/i18n/` **يُقرأ ولا يُكتب**. `node scripts/port-locales.mjs` يحمّله في سياق
شبيه بالمتصفّح ويلتقط ما مُرِّر إلى `I18N.define` بنصّه، فلا تُعاد كتابة **٦٥٠ مفتاحاً ×
٤ لغات** بيد ولا تُترجَم مرّة ثانية.

| ما نُقل كما هو | لماذا |
|---|---|
| نوع `Display` بكل رمياته | الحارس سلوكٌ لا تعليق |
| سلسلة الارتداد المنتهية بالعربية | العربية هي السجلّ (ADR-0021) |
| الإعلان الرباعي عن المفتاح الناقص | الارتداد الصامت خطر بذاته |
| الجمع عبر `Intl.PluralRules` | العربية ستّ فئات، والهندية تضع **الصفر في فئة one** |
| الأرقام والتواريخ من ملفّ اللغة لا من `Intl` | `Intl` تحقن محارف تحكّم تحت `ar` و`ur` |
| تطبيع `٠-٩` و`۰-۹` و`०-९` | لوحة مفاتيح هندية تلصق أرقاماً لا يعرفها التطبيع الثنائي |

| ما تغيّر في النقل | لماذا |
|---|---|
| `ES module` بأنواع بدل `IIFE` على `window` | خطوة بناء موجودة أصلاً، والأنواع تكشف الخطأ قبل التشغيل |
| `I18N.apply(root)` و`data-i18n` حُذفا | React يملك الشجرة؛ بديلهما `useT()` و`<Amount>` و`<Num>`، والحدّ نفسه محفوظ |
| **لا يُحقن رابط خطّ خارجي** | لا شبكة خارجة في هذه البيئة، ورابط `<link>` معطّل للرسم يُبقي الصفحة بيضاء. الحقل `font.href` منقول **كبيانات** ويبقى `font.ui` رمزاً على `:root` |
| نسخة `I18n` كائنٌ لا مفرد عام | الاختبارات تبني نسختها فلا تتسرّب حالة بين اختبارين |

`npm run audit:i18n` خليفة `design/audit.js`، ويفحص ثلاثة عشر شيئاً، **وكل فحص فيه يُعلن حجم
ما فحصه ويفشل إن كان صفراً**، ومعه شواهد إيجابية تزرع مخالفة معروفة وتتأكّد أن الكاشف
يلتقطها — كاشفٌ توقّف عن الكشف يمرّ صامتاً على كل شيء.

## ٤ · الاتجاه — خاصية اللغة، ومفروض بالبناء

* خصائص منطقية فقط (`margin-inline-start` لا `margin-left`) — يفحصه الفحص §٧.
* لا `direction` في CSS إلا على خانة رقمية أو نصّ آلي، **ومعها `unicode-bidi: isolate`**.
* `transform` اتجاهي بلا `--flip-x` مخالفة — و`--flip-x` هو الإذن الوحيد.
* كل خانة مالية: `direction:ltr` + `unicode-bidi:isolate` + `text-align:end` +
  `tabular-nums`، فتقع الفاصلة تحت أختها في اللغات الأربع.

### ⚠️ ثلاثة أشياء وجدها هذا الدور بالتشغيل لا بالقراءة

1. **`overflow-x: clip` على الجسم يُبطل اختبار الانزلاق الأفقي بالكامل.** مع `clip` يتساوى
   `scrollWidth` و`clientWidth` دائماً، فينجح الاختبار **بعد زرع عطل انزلاق حقيقي فيه**.
   قيس ذلك هنا: بعد إزالة `clip` وزرع العطل نفسه، فشل الاختبار بـ`Received: 295`. القاعدة:
   الاحتواء يقع داخل حاوية الجدول، لا بإخفاء الانزلاق على الجسم.
2. **`scrollIntoView` عند أول رسم يقفز بالصفحة.** السطر النشط كان يُمرَّر إلى المنظور عند
   التحميل، فيختفي شريط التنقّل فوق الطيّة عند 360 بكسل. ظهر في لقطة الشاشة، لا في قراءة
   الشيفرة. الآن لا يقع التمرير إلا بعد أول حركة من المستخدم.
3. **فاصل الخلايا كان يُصفَّر على `:last-child` بدل `:first-child`** في
   `design/components/components.css` (`table.lines`/`table.data`): الخليّة الأولى يبقى
   لها حدّ بداية يلاصق حدّ الحاوية فيتضاعف، والخليّة الأخيرة يسقط فاصلها الداخلي. مصلَح
   في `src/styles/app.css` لجدول الميزان؛ ومرفوع للمالك في `design/` لأنه ملفّ للقراءة فقط.

## ٤٫١ · ثوابت نظام التصميم — أربعةٌ مفروضة لا موصوفة

كلٌّ منها فحصٌ في `scripts/audit.mjs` **سجلُّه مشتقٌّ من الشيفرة لا مكتوبٌ بيد**، فمكوّنٌ
جديد يدخل السجل من نفسه ويُحمِّر البوّابة حتى يُعطى ما ينقصه. والقرار الحاكم
[`ADR-0066 · design-invariants-are-enforced-not-reviewed`](../docs/decisions/ADR-0068-design-invariants-are-enforced-not-reviewed.md).

| الفحص | القاعدة | من أين يُشتقّ سجلّه | أين تُضيف |
|---|---|---|---|
| **§١١ سلّم المسافات** | كل قيمة إيقاعٍ على `--space-*`، أو مبرَّرةٌ بتعليقٍ ملاصقٍ فيه «خارج السلّم عمداً» | خطواتُ السلّم من `tokens.css`، ونطاقُه كلُّ ملفٍّ فيه `var(--space-` | الملفّ نفسه |
| **§١٢ عمود الأرقام** | خانةُ `<td>`/`<th>` تعرض `<Amount>`/`<Num>`/`<Decimal>`/`<RateValue>`/`<QuantityValue>` تحمل صنفاً رقمياً؛ وكلُّ قاعدةٍ جدوليّة تختار وجهاً تختار `--font-numeric-face` | الأصنافُ الرقمية من كل قاعدةٍ تُعلن `tabular-nums` | صنف الخانة في الشاشة |
| **§١٣ اللمس والضغط والتركيز** | ‏44 بكسل تحت `pointer:coarse`، ورجعُ `:active`، ولا نزعَ لمؤشّر التركيز بلا بديل | السجلُّ من كل قاعدةٍ تُعلن `cursor:pointer` | [`src/styles/touch.css`](src/styles/touch.css) §٢ و§٣ |
| **§١٤ فهرس الأوّليّات** | كلُّ أوّليّةٍ مُصدَّرة من `ui/index.ts` معروضةٌ في `/design` | كتلُ `export {}` في `ui/index.ts` | `screens/design/DesignScreen.tsx` |

> **والقياس الحيّ دليلٌ لا حارس:** `artifacts/polish/rig.mjs` يقيس في كروميوم — قياسَ اللمس
> والضغط وعرضَ الأرقام ونسبةَ رأس الجدول — ويقارن الشجرة بمرجعٍ من git. لا يعمل في البوّابة
> لأنه يحتاج متصفّحاً و`npm ci`، والفحوص الأربعة تعمل قبل التثبيت.

## ٥ · التشغيل الحيّ على الخلفية الحقيقية

الخلفية لا ترسل ترويسات CORS — **وهذا صحيح ومقصود**: الواجهة تُقدَّم من الأصل نفسه في
الإنتاج. في التطوير يقوم وسيط Vite بذلك:

```bash
export PATH=$PATH:/usr/lib/dotnet
dotnet build Babel.slnx -c Release

# قاعدة بيانات ودليل حسابات وفترات — انظر tests/Babel.Api.Tests/ApiTestDatabase.cs
# (الأداة التي استُعملت هنا عابرة وخارج المستودع؛ الخطوات نفسها موصوفة هناك)

ASPNETCORE_URLS=http://127.0.0.1:5080 \
Babel__Ledger__AppConnectionString="Host=127.0.0.1;Port=5432;Database=…;Username=…" \
Babel__Api__Tokens__0__Sha256=$(printf '%s' "$TOKEN" | sha256sum | cut -d' ' -f1) \
Babel__Api__Tokens__0__Tenant=… Babel__Api__Tokens__0__User=… \
Babel__Api__Tokens__0__Companies__0=… \
dotnet src/Babel.Api/bin/Release/net10.0/Babel.Api.dll

cd web && BABEL_API=http://127.0.0.1:5080 npm run dev     # ثم افتح 5173

# وفحص التكامل الحيّ بالعميل المُولَّد نفسه:
BABEL_API=http://127.0.0.1:5080 BABEL_TOKEN=$TOKEN BABEL_COMPANY=$COMPANY \
  node scripts/live-api-check.mjs
```

`scripts/live-api-check.mjs` يُرحّل قيداً حقيقياً بالمبلغ `1000000000000.4013` **بمفتاح
حصانة ثابت** (فإعادة تشغيله لا تُرحِّل قيداً ثانياً)، ثم يقرأ الميزان بالعميل المُولَّد
ويقارن النصّ بايتاً ببايت. يخرج بالرمز 0 عند النجاح، وينشئ حالته بنفسه فيصحّ منفرداً.

| القياس | الرقم | كيف قيس |
|---|---|---|
| مفاتيح اللغة | ٧٠٩ مفتاحاً × ٤ لغات، بلا ناقص ولا يتيم | `npm run audit:i18n` |

| استجابة ضغطة سهم عند ٥٠٠ صفّاً | **وسيط ١١–١٨ مللي ثانية** (٢٠ ضغطة لكل تشغيلة؛ أقصى مشاهَد ٤٤) | نفسه |

⚠️ **غير مقيس:** الأداء على جهاز محاسب حقيقي، وعلى شبكة بطيئة، وعند خمسة آلاف صفّ؛
وأثر تحميل ملفّات اللغات عند الطلب بدل تحميلها كلها مسبقاً.

## ٧ · الخطوط

لا شبكة خارجة من هذه البيئة، فلا يُحمَّل خطّ من CDN. `--font-sans` و`--font-display`
تُكتبان على `:root` من ملفّ اللغة، والاحتياط خطوط النظام. **الخطوط الموصى بها في ملفّات
اللغة (IBM Plex Sans Arabic · Noto Naskh/Nastaliq · Noto Sans Devanagari) تحتاج استضافةً
ذاتية قبل العرض على المالك** — الشكل النهائي لن يُحكَم عليه بعدل قبل ذلك.
