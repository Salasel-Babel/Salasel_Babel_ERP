# مصفوفة الترحيل المحاسبي — مسودة أولية

> **مسودة للنقاش، وليست مرجعاً معتمداً.**
> الغرض منها إعطاء نقطة انطلاق ملموسة لورشة الجولة الثالثة.
> **لا يُبنى كود ترحيل قبل اعتماد المحاسب القانوني للشركة لهذه المصفوفة.**

## كيف تُقرأ

لكل مستند تشغيلي: متى يُرحَّل، وما القيد الذي يولّده، وكيف يُعكس.
رموز الحسابات إشارية وتتبع الهيكل المقترح في [chart-of-accounts.md](chart-of-accounts.md).

## 3. المخزون

### 3.1 صرف مواد لمشروع

| الحساب | مدين | دائن |
|---|---|---|
| 5201 تكلفة مواد المشاريع *(مشروع + بند BOQ + مركز تكلفة)* | التكلفة | |
| 1401 مخزون البضاعة *(المستودع)* | | التكلفة |

**قاعدة:** التكلفة تُحتسب بطريقة التكلفة المعتمدة (متوسط مرجح / FIFO) لحظة الصرف، لا بسعر الشراء الأخير.

### 3.2 تحويل مخزني بين مستودعين

لا قيد مالي إن كان الحساب واحداً. يُنشأ قيد فقط عند اختلاف حساب المخزون بين المستودعين
(مثل مستودع مشروع له حساب مستقل) أو عند وجود تكلفة نقل تُرسمَل.

### 3.3 تسوية جرد

**عجز:**

| الحساب | مدين | دائن |
|---|---|---|
| 5301 عجز وتلف مخزون | قيمة العجز | |
| 1401 مخزون البضاعة | | قيمة العجز |

**زيادة:** العكس (مدين مخزون / دائن حساب فروقات الجرد).

> **قرار مطلوب:** هل يُستوجب رد ضريبة المدخلات على البضاعة التالفة؟ يُراجَع مع المستشار الضريبي.

## 4. نقاط البيع

### 4.1 إغلاق وردية

| الحساب | مدين | دائن |

| 1101 صندوق نقطة البيع | إجمالي المتحصلات النقدية | |

| 1301 العملاء *(للمبيعات الآجلة)* | إجمالي الآجل | |
| 4101 إيرادات المبيعات | | الصافي |
