# Babel ERP — نظام سلاسل بابل الذكي

نظام تخطيط موارد مؤسسية (ERP) عربي/إنجليزي، متعدد الشركات والفروع.

## النطاق المستهدف

- النظام المحاسبي والمالي
- نقاط البيع (POS)
- الموارد البشرية والرواتب
- المقاولات والمشاريع والمستخلصات
- الإدارة العقارية
- المخازن والمشتريات
- تكامل هيئة الزكاة والضريبة والدخل (ZATCA) للفوترة الإلكترونية

## الحالة

**مرحلة التحليل.** لا يوجد كود إنتاج بعد.

وثائق التحليل والمعمارية تُطوَّر على فرع المتعاون `collab/asadrahwan` وتُدمج في `main` بعد مراجعة المالك.

## الفروع

| الفرع | الغرض |
|---|---|
| `main` | فرع المالك — محمي، لا دفع مباشر |
| `collab/asadrahwan` | فرع المتعاون — تجميع أعمال التطوير |
| `claude/*` · `feature/*` · `fix/*` | فروع العمل — تتفرع من فرع المتعاون |
