قيد يومية جديد

كل حقل في هذه الشاشة يدخل في بصمة SHA-256 للقيد. المبالغ NUMERIC(19,4) في قاعدة البيانات وdecimal في الخادم ونصّ بمقياس ثابت في JSON — لا float في أي طبقة.

الحساب البيان مدين (ر.س) دائن (ر.س) حذف
ما الذي يحدث عند الضغط على «ترحيل القيد» نداء خادم واحد · معاملة واحدة
  1. أخذ العدّاد بلا فجوات بـ SELECT … FOR UPDATE — لا SEQUENCE، لأنها تُهدر أرقاماً عند التراجع.
  2. قراءة بصمة القيد السابق تحت القفل نفسه.
  3. حساب SHA-256 فوق بايتات قانونية تشمل رقم التسلسل والبصمة السابقة.
  4. إدراج القيد وسطوره (INSERT فقط).
  5. تحديث إسقاط الأرصدة بعبارة INSERT … ON CONFLICT DO UPDATE واحدة، صفوفها مرتّبة تصاعدياً بالحساب، مع تأكيد عدد الصفوف المتأثرة.
  6. COMMIT — وهنا يعمل القيد المؤجّل الذي يرفض أي قيد غير متوازن.
لا تُترك أي معاملة مفتوحة بانتظار المتصفح: القفل يُؤخذ ويُترك داخل النداء الواحد.
